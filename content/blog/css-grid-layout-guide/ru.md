## Что такое CSS Grid

**CSS Grid** — двумерная система раскладки: она управляет **строками и колонками одновременно**. Flexbox выстраивает элементы в одну линию, Grid — в таблицу из ячеек, которую можно перестраивать без изменения HTML.

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr;
  gap: 24px;
}
```

Здесь две колонки: первая 200px, вторая занимает остаток. Прямые дети контейнера автоматически распределяются по ячейкам.

## Основные понятия

| Понятие | Что это |
|---|---|
| **Трек** | Строка или колонка сетки |
| **Линия** | Граница между треками, нумеруется с 1 |
| **Ячейка** | Пересечение строки и колонки |
| **Область** | Прямоугольник из нескольких ячеек |
| **`gap`** | Промежуток между треками |

## Единица fr

`fr` — доля **свободного места** в контейнере. `1fr 2fr` делит пространство в пропорции 1:2 после вычета фиксированных размеров и `gap`.

```css
grid-template-columns: 240px 1fr 1fr;
```

Первая колонка фиксирована, две другие делят остаток поровну. Повторы удобно записывать через `repeat()`:

```css
grid-template-columns: repeat(4, 1fr);
```

## Размещение элементов по линиям

Элемент можно растянуть на несколько треков, указав линии:

```css
.wide {
  grid-column: 1 / 3;  /* с 1-й по 3-ю линию: две колонки */
}
.tall {
  grid-row: span 2;    /* занять две строки */
}
```

`-1` означает последнюю линию явной сетки, поэтому `grid-column: 1 / -1` растягивает элемент на всю ширину.

## Именованные области

`grid-template-areas` позволяет нарисовать макет прямо в CSS:

```css
.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.page > header { grid-area: header; }
.page > aside  { grid-area: sidebar; }
.page > main   { grid-area: main; }
.page > footer { grid-area: footer; }
```

Код читается как схема страницы, а перестроить макет можно, изменив только строки областей.

## auto-fit и minmax: адаптивность без медиазапросов

```css
grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
```

Браузер сам решает, сколько колонок поместится: каждая не уже 240px и растягивается до доли свободного места. На узком экране — одна колонка, на широком — четыре или больше.

- **`auto-fit`** схлопывает пустые колонки, и элементы растягиваются на всю ширину.
- **`auto-fill`** сохраняет пустые колонки, и элементы остаются своего размера.

## Неявная сетка

Если элементов больше, чем ячеек в описанной сетке, Grid создаёт **неявные** строки. Их размер задаёт `grid-auto-rows`:

```css
.grid {
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: minmax(160px, auto);
}
```

Каждая новая строка будет не ниже 160px и вырастет, если контента больше.

## Шаг за шагом: адаптивный макет страницы

1. Опишите мобильную версию — всё в одну колонку:

```css
.page {
  display: grid;
  gap: 16px;
  grid-template-areas:
    "header"
    "main"
    "sidebar"
    "footer";
}
```

2. На широком экране переставьте области:

```css
@media (min-width: 900px) {
  .page {
    grid-template-columns: 1fr 280px;
    grid-template-areas:
      "header header"
      "main sidebar"
      "footer footer";
  }
}
```

3. Назначьте `grid-area` элементам, как в примере выше. HTML не меняется.

## Шаг за шагом: галерея карточек

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 20px;
}
.gallery img {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
}
```

Карточки сами перестраиваются под ширину экрана, а `aspect-ratio` держит изображения одинаковыми.

## Частые ошибки

- **`1fr` с длинным контентом.** У `1fr` минимум равен `auto`, и широкий контент раздувает колонку. Используйте `minmax(0, 1fr)`.
- **Несовпадение областей.** Каждая строка в `grid-template-areas` должна иметь одинаковое число колонок, а область — быть прямоугольником.
- **Grid для всего подряд.** Для простого ряда кнопок Flexbox проще.
- **Визуальный порядок против порядка в HTML.** Перестановка областей не меняет порядок чтения для клавиатуры и скринридеров.

Подробности — в документации на [MDN](https://developer.mozilla.org/ru/docs/Web/CSS/CSS_grid_layout).

## FAQ

### Grid или Flexbox — что выбрать?

Grid — когда важны и строки, и колонки: макет страницы, галерея, дашборд. Flexbox — для одномерных задач: навигация, ряд кнопок, выравнивание внутри карточки. Часто сетка страницы на Grid, а содержимое блоков на Flexbox.

### Нужны ли медиазапросы при использовании Grid?

Для галерей часто хватает `repeat(auto-fit, minmax(...))`. Для перестройки макета страницы, например перемещения боковой колонки, медиазапросы по-прежнему удобны.

### Поддерживают ли браузеры CSS Grid?

Базовые возможности Grid поддерживаются всеми современными браузерами. Для новых функций проверяйте таблицы совместимости на MDN.
