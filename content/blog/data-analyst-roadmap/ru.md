## План в пяти шагах

Аналитик данных превращает данные в **ответы на вопросы бизнеса**: почему упали продажи, какие клиенты уходят, какая кампания сработала. Инструменты удобно осваивать в таком порядке:

1. **Excel или Google Sheets.**
2. **SQL.**
3. **Статистика.**
4. **Визуализация и BI.**
5. **Python для анализа.**

Каждый следующий шаг расширяет предыдущий: от таблиц на одном листе к базам данных, выводам и автоматизации.

## Шаг 1. Электронные таблицы

- Формулы, относительные и абсолютные ссылки.
- Функции поиска (`XLOOKUP` или `VLOOKUP`), `IF`, `SUMIFS`, `COUNTIFS`.
- **Сводные таблицы** и фильтры.
- Очистка данных: дубликаты, пропуски, разные форматы дат.

**Чекпоинт:** вы берете сырую выгрузку продаж и за короткое время собираете сводку по месяцам, категориям и регионам.

## Шаг 2. SQL

SQL — главный рабочий инструмент аналитика.

- `SELECT`, `WHERE`, `ORDER BY`, агрегатные функции, `GROUP BY` и `HAVING`.
- `JOIN` разных типов и понимание, когда строки дублируются.
- Подзапросы и **CTE**.
- **Оконные функции**: ранжирование, нарастающий итог, сравнение с прошлым периодом.

```sql
WITH monthly AS (
  SELECT DATE_TRUNC('month', order_date) AS month,
         SUM(amount) AS revenue
  FROM orders
  GROUP BY 1
)
SELECT month,
       revenue,
       revenue - LAG(revenue) OVER (ORDER BY month) AS diff
FROM monthly
ORDER BY month;
```

**Чекпоинт:** вы уверенно решаете задачи на джойны и оконные функции и проверяете результат на здравый смысл.

## Шаг 3. Статистика

- Среднее, медиана, разброс, выбросы.
- Распределения и выборки.
- **Корреляция и причинность**: почему одно не доказывает другое.
- Основы **A/B-тестов**: гипотеза, статистическая значимость, размер выборки.

**Чекпоинт:** вы объясняете, почему средний чек может обманывать и когда лучше смотреть на медиану.

## Шаг 4. Визуализация

- Выбор графика под вопрос: динамика, сравнение, доля, распределение.
- **BI-инструменты**: Power BI, Tableau, Looker Studio или аналоги.
- Дашборды: несколько ключевых метрик вместо десятков графиков.
- **Сторителлинг**: вывод, затем доказательства, затем рекомендация.

**Чекпоинт:** человек без технического фона за минуту понимает главный вывод вашего дашборда.

## Шаг 5. Python

- Основы языка и Jupyter Notebook.
- **pandas** для загрузки, очистки и группировки данных.
- **matplotlib** или **seaborn** для графиков.
- Автоматизация повторяющихся отчетов.

```python
import pandas as pd

df = pd.read_csv("orders.csv", parse_dates=["order_date"])
monthly = df.groupby(df["order_date"].dt.to_period("M"))["amount"].sum()
print(monthly.tail())
```

## Идеи кейсов для портфолио

Используйте открытые данные: государственные порталы открытых данных, Kaggle, публичные датасеты городского транспорта или погоды.

| Кейс | Вопрос | Навыки |
|---|---|---|
| Продажи интернет-магазина | Какие категории растут и почему | SQL, сводные, дашборд |
| Отток клиентов | Какие признаки связаны с уходом клиентов | Python, статистика |
| Городской транспорт | Когда и где пиковая нагрузка | Визуализация, работа с датами |
| A/B-тест | Есть ли значимая разница между вариантами | Статистика, интерпретация |

Для каждого кейса пишите короткий отчет: **вопрос, данные, метод, вывод, ограничения, рекомендация**.

## Частые ошибки

- Учить Python раньше SQL и спотыкаться на простых выборках.
- Строить красивые графики без ответа на вопрос.
- Делать выводы о причинах по одной корреляции.
- Не проверять данные на пропуски и дубликаты.

## FAQ

### Нужно ли высшее математическое образование, чтобы стать аналитиком?

Не обязательно. Нужны уверенная базовая статистика, логика и аккуратность. Математический бэкграунд помогает, но не заменяет практику с реальными данными.

### Что важнее для первой работы: SQL или Python?

Для большинства позиций начального уровня SQL важнее, потому что с ним вы работаете каждый день. Python заметно расширяет возможности, но обычно идет вторым.

### Чем аналитик данных отличается от data scientist?

Аналитик отвечает на вопросы о том, что произошло и почему, и помогает принимать решения. Data scientist чаще строит предсказательные модели и глубже работает с машинным обучением.
