## Короткий ответ

Google Формы — бесплатный способ собрать ответы без программиста. Базовый порядок:

1. Откройте forms.google.com и создайте пустую форму или шаблон.
2. Добавьте вопросы нужных типов и отметьте обязательные.
3. Разбейте длинную форму на **разделы** и настройте переходы.
4. Включите **проверку ответов** там, где важен формат.
5. На вкладке «Ответы» привяжите **Google Таблицу** и включите уведомления.
6. Нажмите «Отправить» и поделитесь ссылкой или кодом для встраивания.

## Типы вопросов

| Тип | Когда использовать |
|---|---|
| Текст (строка) | Имя, телефон, email, короткий ответ |
| Текст (абзац) | Отзывы, развёрнутые комментарии |
| Один из списка | Один вариант из нескольких, видны все сразу |
| Несколько из списка | Можно выбрать несколько вариантов |
| Раскрывающийся список | Длинный список, например города |
| Шкала | Оценка от и до, например удовлетворённость |
| Сетка | Оценка нескольких пунктов по одной шкале |
| Дата и время | Запись, бронирование, дедлайны |
| Загрузка файлов | Резюме, фото, документы |

Учтите: для **загрузки файлов** респонденту нужно войти в Google-аккаунт, а файлы сохраняются на Диск владельца формы.

## Разделы и ветвление

Разделы делят форму на страницы. Ветвление позволяет показывать человеку только нужные вопросы:

1. Добавьте разделы кнопкой «Добавить раздел».
2. В вопросе типа «Один из списка» или «Раскрывающийся список» откройте меню из трёх точек и выберите **«Перейти к разделу на основе ответа»**.
3. Для каждого варианта укажите, в какой раздел вести.

Пример: «Вы уже наш клиент?» — «Да» ведёт в раздел про качество сервиса, «Нет» — в раздел про то, как человек о вас узнал.

## Тесты

В настройках включите **«Сделать тестом»**. Затем у каждого вопроса укажите ответ-ключ и количество баллов, при желании добавьте пояснение к правильному и неправильному ответу. Результаты можно показывать сразу после отправки или после ручной проверки — это удобно, если есть вопросы с развёрнутым ответом.

## Проверка ответов

Проверка защищает от мусора в данных. Откройте меню из трёх точек у вопроса и выберите «Проверка ответов»:

- **Число**: больше, меньше, в диапазоне — для возраста или количества.
- **Текст**: содержит, email, URL — для контактов.
- **Длина**: минимум и максимум символов.
- **Регулярное выражение**: для строгих форматов.
- Для «Нескольких из списка»: выбрать не меньше, не больше или ровно N вариантов.

Пример регулярного выражения для узбекского номера в формате +998XXXXXXXXX:

```text
^\+998\d{9}$
```

## Связь с Google Таблицами

На вкладке «Ответы» нажмите **«Связать с Таблицами»**. Каждый новый ответ появится строкой в таблице с отметкой времени. Советы:

- не меняйте столбцы с ответами, а анализируйте их на отдельном листе через формулы;
- если переименуете вопрос в форме, заголовок столбца изменится, и формулы со ссылкой по названию могут сломаться.

## Уведомления на почту

**Встроенный способ:** вкладка «Ответы» → меню из трёх точек → **«Получать уведомления о новых ответах по эл. почте»**. Письмо придёт владельцу формы.

**Свой текст или несколько получателей:** используйте Apps Script в связанной таблице (Расширения → Apps Script):

```javascript
function notifyTeam(e) {
  const lines = Object.entries(e.namedValues)
    .map(([question, answer]) => question + ': ' + answer.join(', '));
  MailApp.sendEmail('team@example.com', 'Новый ответ в форме', lines.join('\n'));
}
```

Затем в разделе «Триггеры» добавьте триггер для `notifyTeam`: источник — «Из таблицы», событие — «При отправке формы».

## Частые ошибки

- Слишком длинная форма без разделов: люди бросают её на середине.
- Нет обязательных полей для контактов, и ответ не с кем обсудить.
- Сбор персональных данных без пояснения, зачем они нужны.
- Ручные правки в листе ответов, которые потом ломают отчёты.

## FAQ

### Можно ли ограничить один ответ на человека?

Да, в настройках есть ограничение «Не более одного ответа». Но для этого респонденту нужно войти в Google-аккаунт, что может отпугнуть часть аудитории.

### Как встроить форму на сайт?

Нажмите «Отправить», выберите вкладку со значком кода и скопируйте iframe. Его можно вставить в любой конструктор сайтов или HTML-страницу.

### Можно ли редактировать форму после того, как пошли ответы?

Можно, старые ответы сохранятся. Но удалённый вопрос исчезнет из сводки, а в таблице его столбец останется — учитывайте это при анализе.
