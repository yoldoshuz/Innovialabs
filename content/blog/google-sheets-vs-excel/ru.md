## Короткий ответ

- **Google Таблицы** — когда с данными одновременно работают несколько человек, данные приходят из форм и других сервисов, а объёмы умеренные.
- **Excel** — когда файлы большие, нужна сложная модель, сводные таблицы на сотнях тысяч строк, Power Query, Power Pivot или макросы VBA.

Многие компании используют оба инструмента: Таблицы для живых рабочих списков, Excel для глубокого анализа.

## Сравнение

| Критерий | Google Таблицы | Excel |
|---|---|---|
| Лимит данных | 10 млн ячеек на файл | 1 048 576 строк и 16 384 столбца на лист |
| Совместная работа | Родная, в браузере, по ссылке | Совместное редактирование через OneDrive и SharePoint |
| Автоматизация | Apps Script (JavaScript), макросы | VBA, Power Query, Office Scripts в веб-версии |
| Работа с большими файлами | Замедляется задолго до лимита | Desktop-версия справляется заметно лучше |
| Офлайн | Офлайн-режим в Chrome, нужно включить заранее | Полноценная desktop-программа |
| Подключение внешних данных | IMPORTRANGE, IMPORTXML, API через Apps Script | Power Query: базы данных, файлы, веб-источники |

## Формулы и функции

Базовые функции совпадают: SUM, IF, VLOOKUP, XLOOKUP, SUMIFS, FILTER, UNIQUE, SORT. Различия в специфических:

**Только или прежде всего в Google Таблицах:**

- **QUERY** — SQL-подобные запросы к диапазону;
- **IMPORTRANGE** — данные из другой таблицы;
- **GOOGLEFINANCE**, **GOOGLETRANSLATE**, **IMAGE** — встроенные сервисы Google.

```text
=QUERY(A1:D; "select A, sum(D) where B = 'Ташкент' group by A"; 1)
```

**Сильные стороны Excel:**

- **Power Query** — загрузка и очистка данных из множества источников без формул;
- **Power Pivot** и модель данных — связи между таблицами и меры на DAX;
- расширенные сводные таблицы, срезы и анализ «что если».

Формулы между программами переносятся не всегда: функции, которых нет в другой программе, при открытии файла выдадут ошибку.

## Совместная работа

В Google Таблицах несколько человек правят файл одновременно, видят курсоры друг друга, оставляют комментарии и смотрят историю версий. Можно **защитить диапазоны и листы**, чтобы коллеги не сломали формулы.

В Excel совместное редактирование работает, если файл лежит в OneDrive или SharePoint. При обмене файлами по почте появляются копии «отчёт_финал_2.xlsx», и единого источника данных больше нет.

## Автоматизация

**Apps Script** — JavaScript в облаке Google. Подходит для отправки писем, создания документов по шаблону, запросов к API, запуска по расписанию или по событию, например при отправке формы. Скрипт работает на серверах Google, даже когда компьютер выключен.

**VBA** — классические макросы Excel. Мощно для работы внутри desktop-версии, но не работает в веб-версии и требует включённых макросов, что часто ограничено политиками безопасности.

**Power Query** — не программирование, а записанные шаги преобразования данных. Обновляете источник, нажимаете «Обновить» — отчёт пересобран.

## Как выбрать

1. **Сколько людей работает с файлом одновременно?** Больше одного-двух — склоняйтесь к Таблицам.
2. **Какой объём данных?** Десятки и сотни тысяч строк с формулами — Excel.
3. **Откуда данные?** Формы, CRM через API, другие сервисы Google — Таблицы. Базы данных и выгрузки, которые нужно чистить, — Excel с Power Query.
4. **Нужен ли офлайн?** Регулярная работа без интернета — Excel.
5. **Что у партнёров?** Если вам присылают сложные .xlsx с макросами, без Excel не обойтись.

## Частые ошибки

- Хранить в Таблицах большой массив данных с тысячами формул и удивляться медленной работе. Таблица — не база данных.
- Пересылать Excel-файлы по почте вместо общего облачного хранилища.
- Строить критичный процесс на макросе, который понимает только один сотрудник.

## FAQ

### Можно ли открыть файл Excel в Google Таблицах?

Да, файлы .xlsx открываются и редактируются, их можно конвертировать в формат Таблиц. Макросы VBA не выполняются, а некоторые функции и форматирование могут отличаться.

### Что делать, если Google Таблица стала тормозить?

Уберите лишние формулы с целых столбцов, замените тяжёлые IMPORTRANGE и QUERY статичными данными там, где это возможно, и разнесите данные по нескольким файлам. Если объём продолжает расти, пора переходить на Excel или базу данных.

### Нужно ли учить программирование для автоматизации?

Для простых задач — нет: хватит формул, записи макросов и Power Query. Для писем, интеграций и запуска по расписанию понадобятся основы JavaScript для Apps Script или VBA для Excel.
