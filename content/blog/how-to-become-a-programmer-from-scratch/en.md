## The short answer: from zero to a first job

You can become a programmer from scratch, but not through a course or certificate alone. What gets you there is **consistent practice and finished projects**. The path looks like this:

1. Choose one direction.
2. Learn the basics of one language and the core tools.
3. Build several small projects, then 2-3 more serious ones.
4. Put together a portfolio and a resume.
5. Apply for jobs and go through interviews.

The most common beginner mistake is trying to learn everything at once. You become a programmer not when you know many technologies, but when you can **take a task to a working result on your own**.

## Step 1. Choose a direction

The direction decides your language and tools. You are not choosing for life, just for the next year.

| Direction | What you build | Where to start |
|---|---|---|
| **Frontend** | Interfaces for websites and web apps | HTML, CSS, JavaScript |
| **Backend** | Server logic, APIs, databases | Python, JavaScript (Node.js), Java, Go or PHP plus SQL |
| **Mobile** | iOS and Android apps | Kotlin, Swift or cross-platform Flutter |
| **Data / analytics** | Working with data and reports | SQL, Python, basic statistics |

If you are unsure, start with the web: you see results immediately, and the fundamentals carry over to every other direction.

## Step 2. Build the foundation

Whatever you choose, you will need:

- **Language basics**: variables, conditions, loops, functions, data structures.
- **Git**: commits, branches, working with a remote repository.
- **The command line**: navigating, running programs, installing packages.
- **How the internet works**: HTTP requests, client and server, what an API is.
- **Finding answers**: reading documentation and error messages.

```bash
git init
git add .
git commit -m "first project"
```

You will use these commands every day, so get used to them from your very first project.

## Step 3. Learn through projects

Theory without practice fades quickly. A good rhythm: learn a topic, then apply it right away in a small project.

- **First projects**: a calculator, a to-do list, a personal page, a simple bot.
- **Portfolio projects**: something real people could use. For example, a website for a friend's business, a Telegram bot for tracking something, or an app with sign-in and a database.

A portfolio project should be **finished**: a README, a clear code structure and, where possible, a live version.

## Resources: free and paid

- **Free**: official documentation for languages and frameworks, open textbooks, video courses, practice problems on training platforms.
- **Paid courses** give structure, deadlines and mentor feedback. That helps if self-study is hard for you, but a course alone does not guarantee a job.

Pick one main source and avoid jumping between ten courses at once.

## How long it takes

There is no fixed timeline. It depends on several factors:

- **How many hours a week** you actually study.
- **How regularly**: an hour a day beats one long session a week.
- **Whether you get feedback**: a mentor or code review speeds things up noticeably.
- **Your direction** and what the local job market asks for.

Track readiness signals rather than the calendar.

## Signs you are ready to apply

- You can build a small app from scratch without a step-by-step tutorial.
- You have 2-3 projects on GitHub you are comfortable showing.
- You understand how your code works and can explain your decisions.
- You can debug errors using documentation and search.
- You use Git without fear of breaking things.

The feeling that you do not know enough yet never fully goes away, and that is normal. Start applying once the points above are true.

## Common mistakes

- **Endless tutorials** without projects of your own.
- **Switching direction** every couple of weeks.
- **Isolation**: learning without a community or feedback is much harder.
- **Waiting for the perfect resume** instead of sending real applications.

## FAQ

### Do I need a university degree to become a programmer?

For most companies, skills and a portfolio matter more than a diploma. A relevant degree helps with fundamentals, but not having one does not close the door to the profession.

### Which programming language should I learn first?

The one that matches your direction. For the web that is JavaScript; for a general-purpose start and data work, Python. Your second language comes much faster than the first.

### Can I learn while keeping my current job?

Yes, many people do. Set aside regular time each week and learn through projects, and you will see progress even with limited hours.
