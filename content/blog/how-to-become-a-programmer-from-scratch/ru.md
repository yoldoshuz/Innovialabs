## Коротко: путь от нуля до первой работы

Стать программистом с нуля реально, но не за счет курса или сертификата, а за счет **регулярной практики и законченных проектов**. Путь выглядит так:

1. Выбрать одно направление.
2. Освоить основы одного языка и базовые инструменты.
3. Написать несколько небольших проектов, а затем 2-3 проекта посерьезнее.
4. Собрать портфолио и резюме.
5. Откликаться на вакансии и проходить собеседования.

Главная ошибка новичков — пытаться выучить все сразу. Программистом становятся не тогда, когда знают много технологий, а когда умеют **самостоятельно довести задачу до работающего результата**.

## Шаг 1. Выберите направление

Направление определяет язык и инструменты. Не нужно выбирать «на всю жизнь» — достаточно выбрать на ближайший год.

| Направление | Что делаете | С чего начать |
|---|---|---|
| **Frontend** | Интерфейсы сайтов и веб-приложений | HTML, CSS, JavaScript |
| **Backend** | Серверная логика, API, базы данных | Python, JavaScript (Node.js), Java, Go или PHP + SQL |
| **Мобильная разработка** | Приложения для iOS и Android | Kotlin, Swift или кроссплатформенный Flutter |
| **Data / аналитика** | Работа с данными и отчетами | SQL, Python, основы статистики |

Если не знаете, что вам ближе, начните с веба: результат виден сразу, а базовые знания пригодятся в любом направлении.

## Шаг 2. Освойте фундамент

Независимо от направления, понадобятся:

- **Основы языка**: переменные, условия, циклы, функции, структуры данных.
- **Git**: коммиты, ветки, работа с удаленным репозиторием.
- **Командная строка**: навигация, запуск программ, установка пакетов.
- **Как работает интернет**: HTTP-запросы, клиент и сервер, что такое API.
- **Умение искать ответы**: читать документацию и сообщения об ошибках.

```bash
git init
git add .
git commit -m "first project"
```

Эти несколько команд вы будете использовать каждый день, поэтому привыкайте к ним с первого проекта.

## Шаг 3. Учитесь через проекты

Теория без практики быстро забывается. Хорошая схема: изучили тему — сразу применили ее в маленьком проекте.

- **Первые проекты**: калькулятор, список задач, страница-визитка, простой бот.
- **Проекты для портфолио**: что-то, чем могут пользоваться реальные люди. Например, сайт для знакомого бизнеса, Telegram-бот для учета, приложение с авторизацией и базой данных.

Проект для портфолио должен быть **законченным**: с README, понятной структурой кода и, если возможно, опубликованной версией.

## Ресурсы: бесплатные и платные

- **Бесплатные**: официальная документация языков и фреймворков, открытые учебники, видеокурсы, задачи на тренировочных платформах.
- **Платные курсы** дают структуру, дедлайны и обратную связь от наставника. Это полезно, если вам сложно учиться самостоятельно, но сам по себе курс работу не гарантирует.

Выбирайте один основной источник и не переключайтесь между десятью курсами одновременно.

## Сколько времени это занимает

Точного срока нет — он зависит от нескольких факторов:

- **Сколько часов в неделю** вы реально занимаетесь.
- **Насколько регулярно**: ежедневный час дает больше, чем один длинный день в неделю.
- **Есть ли обратная связь**: ментор или код-ревью заметно ускоряют рост.
- **Выбранное направление** и требования рынка в вашем городе.

Ориентируйтесь не на календарь, а на признаки готовности.

## Признаки, что вы готовы искать работу

- Вы можете с нуля сделать небольшое приложение без пошагового туториала.
- У вас есть 2-3 проекта в GitHub, которые не стыдно показать.
- Вы понимаете, как ваш код работает, и можете объяснить свои решения.
- Вы умеете разбираться с ошибками через документацию и поиск.
- Вы работаете с Git без страха что-то сломать.

Ощущение «я еще недостаточно знаю» не пройдет никогда — это нормально. Начинайте откликаться, когда выполнены пункты выше.

## Типичные ошибки

- **Бесконечные туториалы** без собственных проектов.
- **Смена направления** каждые пару недель.
- **Изоляция**: учиться без сообщества и обратной связи тяжелее.
- **Ожидание идеального резюме** вместо реальных откликов.

## FAQ

### Нужно ли высшее образование, чтобы стать программистом?

Для большинства компаний важнее навыки и портфолио, чем диплом. Профильное образование помогает с фундаментом, но его отсутствие не закрывает путь в профессию.

### Какой язык программирования выбрать первым?

Тот, что соответствует выбранному направлению. Для веба это JavaScript, для универсального старта и анализа данных — Python. Второй язык осваивается намного быстрее первого.

### Можно ли учиться параллельно с работой?

Да, многие так и делают. Важно выделить регулярное время в неделю и учиться через проекты — так прогресс будет заметен даже при небольшом количестве часов.
