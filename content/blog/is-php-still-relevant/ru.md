## Короткий ответ

**PHP по-прежнему актуален.** На нём работает значительная часть сайтов в интернете — во многом благодаря WordPress, но не только. За последние годы язык сильно изменился: PHP 8 и последующие версии мало похожи на PHP 5 из старых шуток про «спагетти-код». Для типичных веб-продуктов — сайтов, интернет-магазинов, CRM, API — это зрелый и практичный выбор.

## Что появилось в современном PHP

- **Типы.** Типизированные параметры, возвращаемые значения и свойства классов, union-типы, `mixed`, `never`. Режим `declare(strict_types=1)` запрещает неявные преобразования.
- **Enum.** Перечисления вместо набора строковых констант.
- **Readonly-свойства и классы.** Удобно для неизменяемых объектов-значений.
- **Атрибуты.** Метаданные прямо в коде вместо аннотаций в комментариях — их используют фреймворки для маршрутов, валидации, ORM.
- **Именованные аргументы и `match`.** Код становится короче и понятнее.
- **JIT-компилятор.** Ускоряет вычислительно тяжёлый код. Для обычных веб-запросов, где время уходит на базу и сеть, эффект скромнее, но важнее **OPcache**, который кеширует скомпилированный код.

```php
<?php
declare(strict_types=1);

enum Status: string {
    case New = 'new';
    case Paid = 'paid';
}

final class Order {
    public function __construct(
        public readonly int $id,
        public readonly Status $status,
    ) {}
}

$order = new Order(id: 42, status: Status::Paid);

echo match ($order->status) {
    Status::New  => 'Ожидает оплаты',
    Status::Paid => 'Оплачен',
};
```

## Экосистема: Laravel и Symfony

| | Laravel | Symfony |
|---|---|---|
| Философия | Скорость разработки, много готового | Гибкие компоненты, строгая архитектура |
| Порог входа | Ниже | Выше |
| Где хорош | MVP, SaaS, админки, API | Крупные корпоративные системы |
| Инструменты | Eloquent ORM, очереди, Livewire, Filament | Doctrine ORM, Messenger, компоненты |

Вокруг них — **Composer** для зависимостей, **PHPStan** и **Psalm** для статического анализа, **PHPUnit** и **Pest** для тестов. Для долгоживущих процессов и высокой нагрузки есть Laravel Octane, RoadRunner, FrankenPHP и Swoole.

## Сильные стороны PHP

- **Быстрый старт веб-проекта.** Авторизация, очереди, почта, миграции — всё есть во фреймворках.
- **Дешёвый и простой хостинг.** PHP поддерживается практически везде.
- **Модель «запрос — ответ».** Каждый запрос изолирован, утечки памяти редко накапливаются.
- **Большой рынок разработчиков**, в том числе в Узбекистане и СНГ.
- **CMS и e-commerce**: WordPress, WooCommerce, Magento, Bitrix и другие.

## Когда лучше выбрать другой язык

- **Real-time и множество постоянных соединений** (чаты, игры, стриминг) — естественнее Node.js, Go или Elixir.
- **Машинное обучение и анализ данных** — Python.
- **Высоконагруженные сетевые сервисы и инфраструктура** — Go или Rust.
- **Мобильные и десктопные приложения** — PHP здесь не используют.
- **Команда уже сильна в другом стеке** — смена языка ради моды не окупается.

## Частые ошибки

- Судить о PHP по старому коду без типов и фреймворков.
- Оставаться на неподдерживаемой версии PHP — это риск безопасности. Следите за сроками поддержки на php.net.
- Писать без статического анализа и тестов, хотя инструменты для этого зрелые.

## FAQ

### Стоит ли учить PHP в качестве первого языка?

Если цель — веб-разработка и быстрый выход на работу, PHP вместе с Laravel — разумный путь. Для более широкого старта многие выбирают Python или JavaScript, а PHP добавляют позже.

### PHP медленный?

Современный PHP с OPcache достаточно быстр для подавляющего большинства веб-проектов. Узкое место обычно в базе данных, запросах и архитектуре, а не в самом языке.

### Переписывать ли старый PHP-проект на другой язык?

Чаще выгоднее обновить версию PHP, перейти на фреймворк и постепенно рефакторить. Полное переписывание оправдано, только если язык действительно мешает задачам бизнеса.
