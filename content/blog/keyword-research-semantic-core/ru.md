## Что такое семантическое ядро и зачем оно нужно

**Семантическое ядро** — это список поисковых запросов, по которым ваша целевая аудитория ищет то, что вы предлагаете, сгруппированный по страницам сайта. Оно отвечает на два вопроса: **какие страницы нужны** и **о чём должна быть каждая из них**. Без ядра сайт растёт хаотично: страницы конкурируют друг с другом, а важные темы остаются непокрытыми.

## Шаг 1. Маркерные запросы

Начните с **маркеров** — коротких фраз из 1–3 слов, описывающих ваши товары, услуги и проблемы клиентов.

- Выпишите все категории и услуги.
- Добавьте синонимы и разговорные варианты («разработка сайтов», «создание сайта», «сделать сайт»).
- Посмотрите формулировки клиентов в заявках, переписке, отзывах.
- Изучите меню и заголовки конкурентов.

## Шаг 2. Расширение

Каждый маркер расширяется в десятки и сотни длинных запросов.

| Инструмент | Тип | Для чего |
|---|---|---|
| Яндекс Вордстат | Бесплатный | Частотность и расширения для Яндекса |
| Google Keyword Planner | Бесплатный (нужен аккаунт Google Ads) | Идеи и диапазоны частотности для Google |
| Google Search Console | Бесплатный | Запросы, по которым сайт уже показывается |
| Поисковые подсказки | Бесплатно | Реальные формулировки пользователей |
| Key Collector | Платный | Массовый сбор и обработка запросов |
| Serpstat, Semrush, Ahrefs | Платные | Запросы конкурентов, сложность, объёмы |

Для небольшого сайта хватит бесплатных источников. Платные инструменты экономят время на больших проектах и анализе конкурентов.

## Шаг 3. Чистка

Сырой список почти всегда наполовину мусор. Удалите:

- **Нецелевые запросы**: «бесплатно», «своими руками», «скачать», если вы продаёте услугу.
- **Чужие бренды и города**, где вас нет.
- **Запросы с нулевой точной частотностью** — проверяйте её операторами, а не только общей цифрой.
- **Дубли** и перестановки слов.

Создайте **список минус-слов** — он пригодится и для контекстной рекламы.

## Шаг 4. Кластеризация

Запросы объединяют в группы, которые можно продвигать **одной страницей**. Надёжнее всего группировать **по выдаче**: если по двум запросам в топ-10 много одних и тех же URL, поисковик считает их одной темой.

- **Жёсткая кластеризация** — запросы группируются, только если все пары имеют достаточно общих URL. Группы точнее, но их больше.
- **Мягкая** — достаточно связи с главным запросом группы. Групп меньше, но риск смешать интенты выше.

Кластеризацию по выдаче умеют делать платные сервисы и Key Collector. Вручную небольшое ядро можно сгруппировать по смыслу и затем проверить спорные пары в выдаче.

Также учитывайте **интент**: «купить диван» (коммерческий) и «как выбрать диван» (информационный) — разные страницы, даже если слова похожи.

## Шаг 5. Распределение по страницам

Каждому кластеру — **одна страница**:

1. Коммерческие кластеры — категории, услуги, карточки товаров.
2. Информационные — статьи блога и FAQ.
3. Главный запрос кластера — в title и H1, остальные — естественно в тексте и подзаголовках.
4. Кластеры без подходящей страницы — план для создания новых.

Сведите всё в таблицу: кластер, запросы, частотность, интент, URL, статус.

## Частые ошибки

- **Ориентироваться только на высокочастотные запросы** — конкуренция огромная, а конверсия часто ниже, чем у длинных запросов.
- **Несколько страниц под один кластер** — каннибализация, они мешают друг другу.
- **Смешивать интенты** на одной странице.
- **Собрать ядро один раз и забыть** — спрос меняется, ядро стоит обновлять.

## FAQ

### Сколько запросов должно быть в ядре?

Столько, сколько нужно, чтобы покрыть ваш реальный ассортимент и вопросы клиентов. Для лендинга это может быть несколько десятков, для магазина — тысячи.

### Можно ли собрать ядро без платных инструментов?

Да. Вордстат, Keyword Planner, Search Console и подсказки дают достаточно данных для небольшого и среднего сайта. Платные сервисы ускоряют работу и кластеризацию.

### Нужно ли отдельное ядро для каждого языка?

Да. Люди ищут на разных языках по-разному, и прямой перевод запросов часто не совпадает с реальными формулировками. Собирайте семантику для каждой языковой версии отдельно.
