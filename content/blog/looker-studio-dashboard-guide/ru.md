## Короткий ответ

**Looker Studio** (бывший Google Data Studio) — бесплатный веб-инструмент Google для дашбордов. Нужен только Google-аккаунт. Порядок работы:

1. Подготовить таблицу-источник.
2. Подключить её как **источник данных** (data source).
3. Собрать отчёт: графики, таблицы, фильтры.
4. Добавить **вычисляемые поля**.
5. Поделиться — с правильными правами.

## Готовим Google Sheets к подключению

Большинство проблем в Looker Studio начинается в таблице. Правила простые:

- **Одна строка заголовков**, без объединённых ячеек и пустых столбцов.
- **Одна строка — одна запись** (заказ, лид, визит), без промежуточных итогов внутри данных.
- В каждом столбце **один тип**: даты только датами, суммы без текста вроде «около 500».
- Месяцы — не по столбцам, а в одном столбце «дата».
- Отдельный лист для «сырых» данных, отдельный — для заметок и расчётов.

Если строк очень много, Sheets начинает тормозить — это сигнал переносить данные в **BigQuery** или обычную базу.

## Подключаем источники

Create → Data source → выберите коннектор:

| Источник | Когда использовать |
|---|---|
| **Google Sheets** | Небольшие данные, ручной ввод, выгрузки из CRM |
| **BigQuery** | Большие объёмы, данные из разных систем |
| **GA4, Google Ads, Search Console** | Маркетинговая аналитика |
| **MySQL, PostgreSQL** | Прямое подключение к базе приложения |
| **Партнёрские коннекторы** | Соцсети, рекламные кабинеты; часто платные |

После подключения проверьте типы полей: даты должны быть **Date**, суммы — **Number** или **Currency**, а агрегация по умолчанию — Sum или Count там, где это нужно.

Про **BigQuery** помните: каждый запрос дашборда к нему может тарифицироваться. Делайте небольшие агрегированные таблицы или представления под дашборд и включите кэширование через настройку **Data freshness**.

## Собираем графики, фильтры и вычисляемые поля

Базовый набор страницы:

- **Scorecard** — ключевые цифры с сравнением с прошлым периодом.
- **Time series** — динамика по дням или неделям.
- **Bar chart** — разбивка по каналам или категориям.
- **Table** — детализация с сортировкой.

Интерактивность дают элементы управления: **Date range control**, **Drop-down list** по каналу или городу. Включите **cross-filtering**, чтобы клик по графику фильтровал всю страницу.

**Вычисляемые поля** создаются в источнике данных (Add a field) или прямо в графике. Средний чек:

```sql
SUM(revenue) / COUNT_DISTINCT(order_id)
```

Группировка каналов:

```sql
CASE
  WHEN source IN ("google", "yandex") THEN "Поиск"
  WHEN source = "telegram" THEN "Telegram"
  ELSE "Другое"
END
```

Поля, созданные в источнике, доступны во всех отчётах на его основе — так проще поддерживать единые формулы.

Если нужно соединить две таблицы (например, расходы на рекламу и заявки), используйте **Blend data** с общим ключом — датой или кампанией.

## Делимся дашбордом безопасно

Здесь чаще всего ошибаются. Проверьте три вещи.

**1. Чьи учётные данные использует источник.** В настройках источника есть **Data credentials**:

- **Owner's credentials** — зрители видят данные через ваш доступ, даже если сами к таблице доступа не имеют.
- **Viewer's credentials** — каждый видит только то, к чему у него есть доступ.

Для конфиденциальных данных выбирайте второй вариант или делайте отдельную таблицу только с тем, что можно показывать.

**2. Кому и как открыт отчёт.**

- Делитесь с конкретными людьми или группой, а не «всем, у кого есть ссылка».
- Давайте **Viewer** по умолчанию, **Editor** — только тем, кто правит отчёт.
- Отключите скачивание, печать и копирование для зрителей, если данные чувствительные.

**3. Что лежит в самом источнике.** Даже при скрытом столбце редактор отчёта видит все поля источника. Не подключайте лишнее — персональные данные клиентов в дашборде продаж обычно не нужны.

## FAQ

### Looker Studio действительно бесплатный?

Основная версия бесплатна. Платными могут быть партнёрские коннекторы, запросы к BigQuery и версия Looker Studio Pro с дополнительными функциями управления для команд.

### Почему дашборд показывает устаревшие данные?

Looker Studio кэширует ответы источников. Проверьте **Data freshness** в настройках источника или нажмите обновление данных в меню отчёта. Для Sheets также убедитесь, что новые строки попадают в подключённый диапазон.

### Можно ли встроить дашборд на сайт?

Да, через File → Embed report. Встроенный отчёт подчиняется тем же настройкам доступа: чтобы его видели все посетители, его придётся открыть публично. Поэтому так стоит показывать только данные, которые можно публиковать.
