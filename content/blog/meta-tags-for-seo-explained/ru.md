## Какие мета-теги действительно важны

Мета-теги — это служебные строки в `<head>` страницы, которые читают поисковики, браузеры и соцсети. Не все они одинаково полезны:

| Тег | Влияет на ранжирование | Зачем нужен |
|---|---|---|
| `title` | Да | Заголовок в выдаче и вкладке браузера |
| `meta description` | Нет напрямую | Текст сниппета, влияет на клики |
| `meta robots` | Управляет индексацией | Запрет индексации или перехода по ссылкам |
| `meta viewport` | Косвенно | Корректная мобильная версия |
| Open Graph | Нет | Превью ссылки в соцсетях и мессенджерах |
| `meta keywords` | Google — нет | Устарел |

## Title: главный тег страницы

**Title** — один из самых сильных on-page сигналов. Он показывается заголовком в выдаче, хотя поисковик может его переписать, если сочтет неудачным.

Как писать:

- уникальный для каждой страницы;
- главное — в начале, основной запрос — естественно, без перечисления;
- достаточно коротко, чтобы не обрезался в выдаче;
- название бренда — в конце, через разделитель.

## Description: не для позиций, а для кликов

**Meta description** не влияет на ранжирование напрямую, но часто используется как текст сниппета. Хорошее описание повышает шанс, что пользователь выберет именно вашу ссылку.

- Опишите, что человек найдет на странице, одним-двумя предложениями.
- Делайте уникальное описание для каждой страницы.
- Не дублируйте title и не перечисляйте ключевые слова.

Поисковик может заменить description фрагментом текста страницы, если тот лучше отвечает на запрос, — это нормально.

## Robots: управление индексацией

`meta robots` говорит поисковику, что делать со страницей:

- `noindex` — не показывать в выдаче;
- `nofollow` — не переходить по ссылкам со страницы.

Типичное применение — служебные страницы, результаты внутреннего поиска, корзина. Частая ошибка — оставить `noindex` после разработки на тестовом стенде и выкатить его на рабочий сайт.

Важно: если страница закрыта в robots.txt, робот не увидит на ней `noindex`. Для удаления страницы из индекса ее нужно оставить доступной для обхода.

## Viewport: мобильная версия

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Без этого тега мобильный браузер отрисует страницу как десктопную в уменьшенном виде. Поисковики оценивают прежде всего мобильную версию, поэтому тег обязателен.

## Open Graph: как выглядит ссылка при репосте

Теги `og:title`, `og:description`, `og:image` и `og:url` определяют превью ссылки в Telegram, Facebook, LinkedIn и других сервисах. На позиции они не влияют, но сильно влияют на то, кликнут ли по ссылке при репосте. Для X (Twitter) дополнительно используются теги `twitter:card`.

```html
<meta property="og:title" content="Название страницы">
<meta property="og:description" content="Короткое описание">
<meta property="og:image" content="https://example.com/cover.png">
```

## Keywords: устаревший тег

`meta keywords` когда-то перечислял ключевые слова страницы. Из-за злоупотреблений Google давно его не использует для ранжирования. Заполнять его не нужно, а длинный список ключей может подсказать конкурентам вашу семантику.

## Частые ошибки

- Одинаковые title и description на многих страницах.
- Пустой title или title вида «Главная».
- Случайный `noindex` на важных страницах.
- Отсутствие `og:image` — ссылка в мессенджере выглядит пустой.
- Переспам ключевыми словами в title.

## FAQ

### Почему Google показывает не мой title или description?

Поисковик переписывает их, если считает, что другой текст лучше отвечает на конкретный запрос. Сделайте title и description точнее соответствующими содержанию страницы — это снижает вероятность замены.

### Нужно ли заполнять meta keywords для Яндекса?

Практической пользы нет. Тратьте время на title, description и качество контента.

### Влияет ли Open Graph на SEO?

На позиции напрямую — нет. Но аккуратное превью увеличивает переходы из соцсетей и мессенджеров.
