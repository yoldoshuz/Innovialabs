## Коротко: что такое Miro

**Miro** — это онлайн-доска без границ, на которой несколько человек одновременно работают в реальном времени. На доску можно добавлять стикеры, фигуры, стрелки, текст, изображения, документы, таблицы и встраивать ссылки. Каждый видит курсоры коллег и изменения сразу.

Главная ценность — **общее визуальное пространство** для задач, которые плохо ложатся в документы и таск-трекеры: поиск идей, разбор процессов, обсуждение структуры продукта.

## Мозговой штурм

Классический сценарий для доски:

1. Сформулируйте вопрос в отдельной **рамке** (frame) вверху.
2. Дайте участникам 5–10 минут на **тихую генерацию**: каждый пишет идеи на своих стикерах.
3. **Сгруппируйте** похожие стикеры в кластеры и подпишите их.
4. Проведите **голосование**, чтобы выбрать идеи для проработки.
5. Перенесите выбранное в задачи с ответственными.

Тихая генерация перед обсуждением помогает услышать не только самых громких участников.

## Карта пути клиента

**Customer Journey Map** удобно строить в виде таблицы на доске: по горизонтали — этапы (узнал, сравнил, купил, пользуется, рекомендует), по вертикали — строки:

- действия клиента;
- точки контакта (сайт, бот, менеджер);
- мысли и эмоции;
- проблемы и барьеры;
- идеи улучшений.

Доска позволяет прикрепить к этапам скриншоты, цитаты из интервью и ссылки на аналитику, и вся команда видит путь клиента целиком.

## Ретроспективы

Для ретроспективы спринта или проекта подойдут простые форматы:

| Формат | Колонки |
|---|---|
| Start / Stop / Continue | Начать, прекратить, продолжать |
| Mad / Sad / Glad | Злит, расстраивает, радует |
| 4L | Понравилось, узнали, не хватало, хотим |

Чтобы ответы были честнее, участники сначала пишут стикеры независимо, а потом их открывают. Заканчивайте ретро конкретными действиями с ответственными и сроками, иначе встреча превращается в разговор.

## Планирование на доске

- **Roadmap** — инициативы по кварталам или месяцам на временной шкале.
- **Story mapping** — пользовательские сценарии по горизонтали, функции под ними по приоритету, линии релизов.
- **Приоритизация** — матрица «ценность / усилия», куда команда раскладывает задачи.
- **Схемы процессов** и архитектуры — блок-схемы и диаграммы с соединителями.

Доска хороша для обсуждения, но не заменяет таск-трекер. Договорённости со встречи переносите в Jira, Trello или аналог; у Miro есть интеграции с популярными трекерами.

## Шаблоны

В Miro есть большая библиотека шаблонов: ретроспективы, CJM, SWOT, roadmap, user story map, канбан, диаграммы. Кроме официальных, есть каталог шаблонов от сообщества — **Miroverse**. Хорошая практика — сделать **свои шаблоны** для повторяющихся встреч, чтобы каждый раз не собирать доску заново.

## Функции фасилитации

Они делают из доски рабочую встречу, а не хаос из стикеров:

- **Таймер** — для тихой генерации и ограничения обсуждения.
- **Голосование** — каждому участнику даётся несколько голосов.
- **Собрать всех к себе** и режим следования за ведущим — участники видят ту же часть доски.
- **Рамки и презентация** — доска показывается последовательно, как слайды.
- **Комментарии и реакции** — для асинхронной работы между встречами.

Часть функций доступна только на платных тарифах; актуальный список проверьте на сайте Miro.

## Бесплатные альтернативы

На бесплатном тарифе Miro число редактируемых досок ограничено. Если этого мало, посмотрите альтернативы:

- **FigJam** — доска от Figma, удобна, если дизайнеры уже работают в Figma.
- **Excalidraw** — open source доска для быстрых схем от руки, можно развернуть на своём сервере.
- **Microsoft Whiteboard** — бесплатная доска для пользователей Microsoft 365.
- **Lucidspark**, **Mural**, **Canva Whiteboards** — у каждого есть бесплатный уровень с ограничениями.

Перед выбором проверьте, доступен ли сервис в вашей стране и где хранятся данные, если на досках будет информация о клиентах.

## FAQ

### Можно ли пригласить на доску человека без аккаунта?

Да, в Miro доску можно открыть по ссылке с правами просмотра, комментирования или редактирования. Доступ гостей зависит от тарифа и настроек безопасности вашей команды.

### Чем Miro отличается от таск-трекера?

Доска нужна для совместного мышления: генерации идей, схем, обсуждений. Таск-трекер нужен для учёта задач, сроков и статусов. Обычно их используют вместе.

### Какая бесплатная альтернатива Miro самая простая?

Для быстрых схем и набросков — Excalidraw: он работает в браузере без регистрации. Для полноценных встреч с шаблонами и голосованием ближе всего FigJam.
