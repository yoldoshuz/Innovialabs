## Коротко

- **Postman** — платформа для API: запросы, тесты, документация, моки, мониторинг. Всё синхронизируется через облако Postman и нужен аккаунт. Лучший выбор, когда с API работают не только разработчики.
- **Insomnia** (от Kong) — аккуратный клиент с поддержкой REST, GraphQL, gRPC и WebSocket. Позволяет выбрать, где хранить данные: только локально, в облаке или в Git.
- **Bruno** — открытый офлайн-клиент без облака. Коллекции хранятся обычными текстовыми файлами в папке проекта, а совместная работа идёт через Git.

## Сравнение по главным критериям

| Критерий | Postman | Insomnia | Bruno |
|---|---|---|---|
| Где хранятся коллекции | Облако Postman | Локально, облако или Git — на выбор | Файлы на диске, обычно в Git |
| Работа без интернета и аккаунта | Ограничена | Есть локальный режим | Да, это основной режим |
| Совместная работа | Общие workspaces, комментарии, роли | Облачная синхронизация или Git | Через Git: ветки и pull request |
| Документация и моки | Встроены и развиты | Есть дизайн OpenAPI, моки | Минимально |
| Автотесты и CLI | Скрипты, Newman, Postman CLI | Скрипты, консольная утилита Inso | Скрипты, Bruno CLI |
| Открытый код | Нет | Ядро открыто | Да |
| Порог входа для не-разработчиков | Самый низкий | Средний | Нужно понимать Git |

Возможности всех трёх быстро меняются, поэтому перед выбором проверьте актуальный список протоколов и функций на официальных сайтах.

## Офлайн и хранение в Git

Это главное различие философий.

- **Bruno** сохраняет каждый запрос отдельным текстовым файлом. Коллекция лежит в репозитории рядом с кодом API, изменения видны в diff, проходят ревью вместе с кодом и никогда не покидают вашу инфраструктуру.
- **Insomnia** даёт выбор: локальное хранилище без облака, облачную синхронизацию или Git Sync. Удобно, если часть команды хочет облако, а часть — нет.
- **Postman** изначально облачный. Коллекции можно экспортировать в JSON и хранить в Git, но это отдельный шаг, а не основной способ работы.

## Совместная работа

- **Postman** сильнее всего, когда в работе с API участвуют QA, аналитики, менеджеры, внешние партнёры: общие рабочие пространства, обновления видны всем сразу, есть комментарии, права доступа и опубликованная документация.
- **Bruno** удобен командам, где все и так работают в Git: изменения в коллекции идут тем же pull request, что и изменения в API.
- **Insomnia** подходит обоим сценариям, но в каждом уступает специализированному решению.

## Цена: от чего она зависит

Конкретные тарифы меняются, поэтому важнее понимать модель:

- **Postman** — бесплатный план с ограничениями на совместную работу и облачные функции, платные планы считаются за пользователя. Стоимость растёт вместе с командой.
- **Insomnia** — бесплатное использование для базовых сценариев, командные функции и облако — в платных планах.
- **Bruno** — основной клиент бесплатный и открытый, часть продвинутых функций вынесена в платную редакцию.

При расчёте учитывайте: сколько людей реально нужен доступ, нужны ли SSO, роли и аудит, сколько запусков, моков и мониторов вы будете использовать.

## Приватность и безопасность

Для API-клиента это вопрос о том, где окажутся токены, ключи и примеры ответов с реальными данными.

- Если коллекции синхронизируются в облако, они хранятся на серверах поставщика. Проверьте, что это допустимо по политике вашей компании и требованиям к хранению данных.
- **Bruno** и локальный режим **Insomnia** не отправляют коллекции в облако.
- В любом инструменте держите секреты в переменных окружения или специальном хранилище секретов, а не в теле запросов.

## Что выбрать под размер команды

| Ситуация | Рекомендация |
|---|---|
| Один разработчик или фрилансер | Любой; Bruno, если хотите хранить запросы в репозитории |
| Небольшая команда разработчиков, всё в Git | **Bruno** |
| Смешанная команда: разработчики, QA, менеджеры, партнёры | **Postman** |
| Строгие требования к данным, облако запрещено | **Bruno** или **Insomnia** в локальном режиме |
| Много gRPC, дизайн API через OpenAPI, инфраструктура Kong | **Insomnia** |
| Крупная компания с SSO и ролями | Postman на корпоративном плане или Bruno с вашим Git-сервером — по требованиям безопасности |

## Частые ошибки

- Выбирать по привычке одного человека, не спросив, кто ещё будет работать с коллекциями.
- Хранить боевые токены в синхронизируемых коллекциях.
- Держать две копии коллекции в разных инструментах — они быстро расходятся.

## FAQ

### Можно ли перейти с Postman на Bruno или Insomnia?

Да. Оба клиента импортируют коллекции Postman. Обычно проверить после переноса нужно скрипты: синтаксис и доступные функции у клиентов различаются.

### Какой клиент лучше для новичка?

Postman: у него больше всего обучающих материалов и самый понятный интерфейс для первых запросов. Перейти на другой клиент позже несложно.

### Нужен ли платный тариф маленькой команде?

Не обязательно. Небольшая команда разработчиков может работать в Bruno через Git без подписки. Платный тариф Postman или Insomnia оправдан, когда нужны облачная совместная работа, роли и расширенные лимиты.
