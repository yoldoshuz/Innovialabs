## Короткий ответ: из чего состоит первый отчёт

Для старта нужен бесплатный **Power BI Desktop** (работает под Windows). Весь путь выглядит так:

1. **Get Data** — подключить Excel и базу данных.
2. **Power Query** — очистить и привести типы.
3. **Модель** — связать таблицы фактов и справочников.
4. **DAX** — написать меры: выручка, число заказов, средний чек.
5. **Публикация** — отправить отчёт в Power BI Service и настроить обновление.

Ниже каждый шаг на примере продаж: таблица заказов в базе и справочник товаров в Excel.

## Шаг 1. Загружаем данные из Excel и базы

- **Excel**: Home → Get Data → Excel workbook. Выберите лист или, лучше, **отформатированную таблицу** (Ctrl+T в Excel) — она устойчивее к добавлению строк.
- **База данных**: Get Data → SQL Server, PostgreSQL или MySQL. Укажите сервер и базу. Для некоторых СУБД может понадобиться установить драйвер.

На этапе подключения выберите режим:

| Режим | Как работает | Когда подходит |
|---|---|---|
| **Import** | Данные копируются в файл отчёта | Большинство отчётов, максимальная скорость |
| **DirectQuery** | Каждый визуал отправляет запрос в базу | Очень большие или почти real-time данные |

Начинайте с **Import** — он проще и прощает ошибки модели.

Совет: не тяните всю таблицу «на всякий случай». Выбирайте только нужные столбцы и период — отчёт будет быстрее и легче.

## Шаг 2. Чистим данные в Power Query

Нажмите **Transform data**. Каждое действие записывается как шаг и повторяется при каждом обновлении — чистить вручную больше не придётся.

Типичный набор шагов:

- **Change Type** — даты как даты, суммы как десятичные числа.
- **Remove Duplicates** по ключу (например, артикулу в справочнике).
- **Trim / Clean** — убрать лишние пробелы, из-за которых связи не находят пару.
- **Replace Values** и **Fill Down** — заполнить пропуски.
- **Unpivot Columns** — если месяцы разложены по столбцам, превратите их в строки.

Переименуйте шаги понятно — через месяц это сильно поможет. Затем **Close & Apply**.

## Шаг 3. Строим модель данных

Откройте вид **Model**. Цель — схема **«звезда»**: в центре таблица фактов (заказы), вокруг справочники (товары, клиенты, даты).

- Связи **один ко многим**: один товар — много строк заказов.
- Направление фильтра — **одинарное**, от справочника к фактам. Двунаправленные связи оставьте для особых случаев.
- Создайте отдельную **таблицу дат** и отметьте её как Date table. Без неё функции сравнения периодов работают ненадёжно.

```dax
Date = CALENDAR ( DATE ( 2023, 1, 1 ), DATE ( 2026, 12, 31 ) )
```

Свяжите `Date[Date]` с датой заказа.

## Шаг 4. Пишем первые меры DAX

**Мера** считается на лету с учётом фильтров на странице, **вычисляемый столбец** — один раз при обновлении для каждой строки. Для итогов почти всегда нужны меры.

```dax
Total Sales = SUM ( Orders[Amount] )
Orders Count = DISTINCTCOUNT ( Orders[OrderID] )
Avg Check = DIVIDE ( [Total Sales], [Orders Count] )
Sales LY = CALCULATE ( [Total Sales], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )
Sales YoY % = DIVIDE ( [Total Sales] - [Sales LY], [Sales LY] )
```

`DIVIDE` безопасно обрабатывает деление на ноль. Храните меры в отдельной пустой таблице, чтобы их было легко найти.

## Шаг 5. Собираем страницу и публикуем

Минимальная страница: карточки с ключевыми мерами, линейный график продаж по датам, столбчатая диаграмма по категориям, **срезы** (slicers) по периоду и региону. Клик по столбцу фильтрует остальные визуалы — это и есть интерактивность.

Публикация: **Publish** → рабочая область в Power BI Service. Дальше:

- Для обновления данных из локальной базы установите **on-premises data gateway** и настройте **scheduled refresh**.
- Для совместного доступа обычно нужны платные лицензии или ёмкость — проверьте условия вашего тарифа.
- Не используйте **Publish to web** для внутренних данных: отчёт становится доступен любому, у кого есть ссылка.

## Частые ошибки новичков

- Одна огромная «плоская» таблица вместо звезды — медленно и сложно считать.
- Суммы в вычисляемых столбцах вместо мер.
- Нет таблицы дат — сравнения с прошлым годом дают странные цифры.
- Ручные правки в Excel-источнике вместо шагов Power Query.
- Десятки визуалов на одной странице. Лучше 5–7 и понятный заголовок.

## FAQ

### Нужна ли платная лицензия, чтобы начать?

Нет. Power BI Desktop бесплатен, в нём можно строить и сохранять отчёты локально. Лицензии становятся важны, когда отчёт нужно публиковать и делиться им с коллегами.

### Чем Power Query отличается от DAX?

Power Query готовит данные до загрузки в модель: чистит, объединяет, меняет форму таблиц. DAX считает показатели поверх уже загруженной модели. Сначала — чистые данные в Power Query, потом — меры в DAX.

### Почему мера показывает одинаковое значение во всех строках?

Чаще всего нет связи между таблицами или направление фильтра не доходит до таблицы фактов. Проверьте связи в виде Model и то, что поле в визуале взято из справочника, связанного с фактами.
