## Что такое тематический авторитет

**Тематический авторитет** — это ситуация, когда поисковая система считает ваш сайт надёжным источником по конкретной теме, а не по отдельному запросу. Сайт, который подробно и последовательно раскрывает тему, обычно ранжируется лучше сайта с одной сильной статьёй и разрозненными заметками вокруг.

Основной инструмент — **модель «pillar + кластер»**:

- **Pillar-страница** — широкий обзор темы, отвечающий на главный вопрос и ведущий ко всем подтемам.
- **Кластерные страницы** — глубокие материалы по каждой подтеме.
- **Перелинковка** связывает их в единую структуру.

## Шаг 1. Составьте карту темы

Начните не со списка ключей, а с вопросов аудитории.

1. Определите **ядро темы** — то, по чему вы хотите быть экспертом.
2. Соберите запросы: подсказки поиска, блок «Похожие вопросы», Wordstat, отчёты Search Console, вопросы от клиентов и отдела продаж.
3. **Сгруппируйте по интенту**, а не по словам: если выдача по двум запросам почти совпадает, это одна страница.
4. Разделите группы на уровни: основные подтемы и узкие вопросы внутри них.

Результат — дерево темы, где каждый лист соответствует одной странице. Отметьте, что уже есть на сайте, а что нужно создать.

## Шаг 2. Спроектируйте pillar-страницу

Хорошая pillar-страница:

- отвечает на общий запрос (например, «складской учёт») полностью, но без глубокого погружения в каждую деталь;
- содержит короткие разделы по каждой подтеме со ссылкой на подробную статью;
- имеет понятную навигацию, например оглавление;
- не превращается в список ссылок — у неё должна быть самостоятельная ценность.

## Шаг 3. Спроектируйте кластерные страницы

Каждая кластерная страница:

- закрывает **один интент** полностью;
- не повторяет соседние страницы — иначе они начнут конкурировать между собой (каннибализация);
- ссылается на pillar и на 2–4 близкие по смыслу статьи кластера.

## Шаг 4. Свяжите всё ссылками

| Связь | Зачем |
|---|---|
| Pillar → каждая кластерная | Показывает поисковику структуру темы |
| Кластерная → pillar | Передаёт вес главной странице темы |
| Кластерная → соседние | Помогает пользователю углубиться |
| Хлебные крошки и разделы | Закрепляют иерархию в URL и навигации |

Используйте **описательные анкоры** («как выбрать WMS-систему»), а не «подробнее» или «здесь». Ссылки должны быть в тексте, где они действительно полезны читателю.

## Шаг 5. Измеряйте результат

Тематический авторитет нельзя увидеть одной цифрой, поэтому смотрите на кластер целиком:

- **Число запросов, по которым видны страницы кластера** в Search Console — рост означает, что поисковик связывает сайт с темой.
- **Доля запросов в топе** по теме, а не позиции отдельных ключей.
- **Скорость ранжирования новых статей** кластера: если новые материалы быстрее попадают в выдачу, авторитет растёт.
- **Органический трафик и конверсии** по группе URL кластера.

Сгруппируйте URL кластера по общему пути (например, `/blog/warehouse/`) или с помощью фильтров, чтобы видеть динамику темы, а не отдельных страниц.

## Частые ошибки

- **Много тонких статей** вместо меньшего количества полных.
- **Каннибализация** — несколько страниц под один интент.
- **Pillar без ссылок на кластер** или кластер без обратных ссылок.
- **Разброс тем**: десяток направлений по чуть-чуть вместо глубины в главном.
- **Публикация и забвение** — устаревшие материалы ослабляют весь кластер.

## FAQ

### Сколько статей нужно в одном кластере?

Фиксированного числа нет. Ориентируйтесь на карту темы: кластер завершён, когда закрыты основные вопросы аудитории без дублей между страницами.

### Можно ли сделать pillar-страницей существующую статью?

Да, если она уже ранжируется по общему запросу. Расширьте её обзорными разделами и добавьте ссылки на кластерные материалы.

### Подходит ли этот подход небольшому сайту?

Да, даже лучше: небольшому сайту выгоднее глубоко раскрыть одну-две темы, чем поверхностно писать обо всём.
