## Коротко

**Visual Studio Code** — бесплатный редактор кода от Microsoft для Windows, macOS и Linux. Чтобы начать:

1. Установите его с официального сайта code.visualstudio.com.
2. Открывайте **папку** проекта, а не отдельные файлы.
3. Запомните два сочетания: **Command Palette** и **Quick Open**.
4. Работайте во **встроенном терминале**, а не в отдельном окне.
5. Включите **Settings Sync** и поменяйте несколько настроек по умолчанию.

Это около получаса, которые потом экономят время каждый день.

## Установка

- **Windows.** Скачайте User Installer. При установке отметьте **Add to PATH** и пункты **Open with Code** для контекстного меню: тогда любую папку можно открыть из проводника или командой `code .` в терминале.
- **macOS.** Скачайте архив, перенесите Visual Studio Code в «Программы». Затем откройте Command Palette и выполните **Shell Command: Install 'code' command in PATH**.
- **Linux.** Используйте пакет `.deb` или `.rpm` с официального сайта или пакет для вашего дистрибутива.

Скачивайте только с официального сайта или из доверенного менеджера пакетов: пересобранные «портативные» версии со случайных сайтов — риск для безопасности.

## Интерфейс за минуту

- **Activity Bar** — полоса иконок слева: Explorer, Search, Source Control (Git), Run and Debug, Extensions.
- **Side Bar** — панель, которую открывают эти иконки, например дерево файлов.
- **Editor** — основная область с вкладками; ее можно разделить, чтобы видеть файлы рядом.
- **Panel** — нижняя область: Terminal, Problems, Output, Debug Console.
- **Status Bar** — нижняя строка: ветка Git, ошибки, язык файла, переводы строк, отступы.

Главные сочетания (на macOS вместо Ctrl — Cmd):

| Действие | Сочетание |
|---|---|
| Command Palette — любая команда по названию | `Ctrl+Shift+P` |
| Quick Open — файл по имени | `Ctrl+P` |
| Показать или скрыть терминал | ``Ctrl+` `` |
| Поиск по всему проекту | `Ctrl+Shift+F` |
| Показать или скрыть боковую панель | `Ctrl+B` |
| Настройки | `Ctrl+,` |

Если запомнить только одно — пусть это будет **Command Palette**: наберите часть названия команды, и VS Code ее найдет.

## Как открывать проекты

**File → Open Folder** или команда `code .` в папке проекта. VS Code считает папку **рабочей областью**: поиск, Git, терминал и настройки проекта работают относительно нее. Недавние проекты — в **File → Open Recent**.

Настройки конкретного проекта хранятся в `.vscode/settings.json` внутри папки и перекрывают личные — удобно, когда команда договорилась об отступах или форматировании.

## Встроенный терминал

Открывается сочетанием ``Ctrl+` ``. Он сразу стартует в папке проекта, поэтому `npm install`, `git status` или `python main.py` запускаются без лишних переходов. Можно открыть несколько терминалов, разделить их и выбрать оболочку: на Windows это PowerShell, Command Prompt или Git Bash. Оболочка по умолчанию задается командой **Terminal: Select Default Profile**.

## Синхронизация настроек

Нажмите на иконку аккаунта слева внизу и включите **Backup and Sync Settings**, войдя через GitHub или Microsoft. VS Code начнет синхронизировать настройки, сочетания клавиш, расширения, сниппеты и состояние интерфейса между компьютерами. На новом ноутбуке достаточно войти — и привычный редактор готов за минуту.

## Темы и шрифты

- **Тема:** Command Palette → **Preferences: Color Theme**. Встроенные Dark Modern и Light Modern — хороший старт, остальные ставятся расширениями.
- **Шрифт:** моноширинный, созданный для кода, например JetBrains Mono, Fira Code или Cascadia Code. Сначала установите его в систему, затем укажите в настройках.
- **Размер:** удобный для долгой работы. `Ctrl+=` и `Ctrl+-` масштабируют весь интерфейс.

## Первые настройки

Откройте из Command Palette **Preferences: Open User Settings (JSON)** и добавьте:

```json
{
  "files.autoSave": "afterDelay",
  "editor.formatOnSave": true,
  "editor.tabSize": 2,
  "editor.wordWrap": "on",
  "editor.fontFamily": "JetBrains Mono, Consolas, monospace",
  "editor.fontSize": 15,
  "editor.fontLigatures": true,
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true,
  "editor.minimap.enabled": false
}
```

- `files.autoSave` — изменения больше не теряются.
- `editor.formatOnSave` — код форматируется при каждом сохранении, когда установлено расширение-форматтер.
- `editor.tabSize` — ширина отступа; следуйте соглашению проекта.
- `files.trimTrailingWhitespace` и `files.insertFinalNewline` — чистые диффы в Git.
- `editor.minimap.enabled` — миникарта занимает место, многие ее отключают.

## FAQ

### VS Code и Visual Studio — это одно и то же?

Нет. Visual Studio — полноценная IDE, в основном для разработки на .NET и C++ под Windows. VS Code — легкий кроссплатформенный редактор, который с расширениями становится IDE почти для любого языка.

### Нужны ли расширения сразу?

Только для вашего языка и форматтер, например Python или ESLint и Prettier. Остальное добавляйте, когда появится конкретная потребность: лишние расширения замедляют редактор.

### Где хранятся мои настройки?

Личные — в файле `settings.json` в профиле пользователя, настройки проекта — в `.vscode/settings.json`. Оба открываются из Command Palette, и настройки проекта имеют приоритет.
