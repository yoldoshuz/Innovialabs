## Что такое DOM

**DOM** (Document Object Model) — это представление страницы в виде дерева объектов. Браузер читает HTML и строит из него структуру: у документа есть `<html>`, внутри — `<head>` и `<body>`, внутри body — заголовки, абзацы, кнопки. Каждый элемент, текст и комментарий — это **узел** дерева.

Важно: DOM — не HTML-файл. HTML — это исходный текст, а DOM — **живая модель в памяти**. JavaScript меняет именно её, и браузер тут же отображает изменения. Если открыть «Просмотр кода», вы увидите исходный HTML; если открыть DevTools → Elements, вы увидите текущий DOM.

## Как найти элемент

```js
const title = document.querySelector("h1");          // первый h1
const buttons = document.querySelectorAll(".btn");  // все .btn
const form = document.getElementById("order-form");
```

- `querySelector` принимает любой CSS-селектор и возвращает первый найденный элемент или `null`.
- `querySelectorAll` возвращает статичный список всех совпадений.

## Как изменить страницу

```js
title.textContent = "Новый заголовок";
title.classList.add("is-active");
form.setAttribute("aria-busy", "true");

const item = document.createElement("li");
item.textContent = "Новый пункт";
document.querySelector("ul").append(item);

item.remove();
```

Пара правил:

- Для текста используйте **textContent**, а не `innerHTML`. Вставка пользовательских данных через `innerHTML` открывает дорогу XSS-атакам.
- Стили лучше менять через **классы**, а не через `element.style`: оформление остаётся в CSS.

## События

Страница реагирует на действия пользователя через **события**: клик, ввод текста, отправка формы, прокрутка.

```js
const button = document.querySelector("#buy");

button.addEventListener("click", (event) => {
  console.log("Клик по", event.target);
});

form.addEventListener("submit", (event) => {
  event.preventDefault(); // не перезагружать страницу
});
```

События **всплывают**: клик по кнопке сначала срабатывает на ней, потом на её родителе, потом выше — до `document`.

## Делегирование событий

Всплытие позволяет повесить один обработчик на контейнер вместо сотни обработчиков на каждый элемент:

```js
document.querySelector("#list").addEventListener("click", (event) => {
  const button = event.target.closest("button[data-id]");
  if (!button) return;
  console.log("Удалить", button.dataset.id);
});
```

Плюсы делегирования:

- **Меньше обработчиков** — меньше памяти и кода.
- **Работает для новых элементов**: пункты, добавленные позже, обрабатываются автоматически.

## Почему фреймворки прячут DOM

В маленьком скрипте прямая работа с DOM — нормально. Но в большом интерфейсе быстро начинаются проблемы:

- состояние хранится в данных и в DOM одновременно, и они **расходятся**;
- нужно вручную помнить, какие элементы обновить при каждом изменении;
- частые изменения вызывают лишние **пересчёты раскладки** (layout) и перерисовки.

React, Vue, Svelte и другие решают это **декларативно**: вы описываете, как интерфейс должен выглядеть при текущих данных, а фреймворк сам вычисляет минимальные изменения DOM. React для этого использует виртуальное дерево, другие — компиляцию или реактивность, но идея одна: разработчик меняет **данные**, а не узлы.

## Частые ошибки новичков

- Искать элемент до того, как он появился. Скрипт в `<head>` без `defer` выполняется раньше, чем построено body.
- Читать размеры элемента и тут же менять стили в цикле — это заставляет браузер раз за разом пересчитывать раскладку.
- Вставлять ввод пользователя через `innerHTML`.
- Вручную менять DOM внутри компонента React или Vue: фреймворк перезапишет эти изменения.

## FAQ

### DOM — это часть JavaScript?

Нет. DOM — это стандартный интерфейс, который предоставляет браузер. JavaScript лишь самый распространённый язык для работы с ним. В Node.js, например, DOM по умолчанию нет.

### Нужно ли изучать DOM, если я пишу на React?

Да, хотя бы основы. События, всплытие, формы, фокус и доступность работают по правилам DOM, а рефы и интеграция со сторонними библиотеками требуют прямого доступа к элементам.

### Что такое Shadow DOM?

Это изолированное поддерево внутри элемента, стили и разметка которого не смешиваются с остальной страницей. Его используют веб-компоненты.
