## Коротко: что такое Go

**Go (Golang)** — язык программирования, созданный в Google и открытый в 2009 году. Его задумали как ответ на медленную сборку и сложность больших C++ и Java-проектов. Главная идея — **простота**: мало ключевых слов, один стиль форматирования, понятная модель конкурентности.

Go компилируется в машинный код, имеет сборщик мусора и строгую статическую типизацию. На нём написаны Docker, Kubernetes, Terraform, Prometheus и множество внутренних сервисов крупных компаний.

## Почему разработчики выбирают Go

- **Простой язык.** Спецификацию можно прочитать за вечер. Новый человек в команде быстро начинает читать чужой код.
- **Быстрая компиляция.** Даже крупные проекты собираются за секунды, что ускоряет цикл «правка — проверка».
- **Один бинарник.** Результат сборки — исполняемый файл без внешних зависимостей. Его легко положить в минимальный Docker-образ или скопировать на сервер.
- **Кросс-компиляция.** Собрать программу под Linux, Windows или macOS можно с одной машины, задав переменные `GOOS` и `GOARCH`.
- **Встроенная конкурентность.** Горутины и каналы — часть языка, а не внешней библиотеки.
- **Сильная стандартная библиотека.** HTTP-сервер, JSON, криптография, тестирование — всё есть «из коробки».
- **Единые инструменты.** `go fmt`, `go test`, `go vet`, `go mod` — одинаковые во всех проектах.

## Горутины и каналы на примере

**Горутина** — лёгкий поток, которым управляет рантайм Go. Их можно запускать тысячами. **Канал** — способ безопасно передавать данные между горутинами.

```go
package main

import "fmt"

func square(n int, out chan<- int) {
	out <- n * n
}

func main() {
	out := make(chan int)
	nums := []int{1, 2, 3, 4}
	for _, n := range nums {
		go square(n, out)
	}
	sum := 0
	for range nums {
		sum += <-out
	}
	fmt.Println(sum) // 30
}
```

Такая модель удобна для сетевых сервисов, где нужно одновременно обрабатывать множество запросов.

## Где Go подходит лучше всего

| Задача | Почему Go |
|---|---|
| REST и gRPC API | Быстрый HTTP-стек, низкое потребление памяти |
| Микросервисы | Маленькие бинарники, быстрый старт контейнера |
| CLI-утилиты | Один файл, кросс-компиляция под любые ОС |
| Облачная инфраструктура | Экосистема Kubernetes и DevOps-инструментов |
| Сетевые сервисы, прокси, очереди | Горутины и эффективный ввод-вывод |

## Где Go — не лучший выбор

- **Сложная доменная логика.** Система типов намеренно простая; для богатых моделей предметной области многим удобнее Kotlin, C# или TypeScript.
- **Data science и ML.** Экосистема Python здесь несравнимо богаче.
- **Десктопные и мобильные интерфейсы.** GUI-библиотеки для Go существуют, но уступают нативным инструментам.
- **Жёсткий real-time и системное программирование.** Сборщик мусора даёт паузы; для таких задач чаще берут Rust или C++.
- **Быстрый прототип сайта с админкой.** Фреймворки вроде Laravel или Django дадут больше готовых функций.

## Типичные ошибки новичков

- Переносить привычки из Java: глубокие иерархии и лишние абстракции. В Go ценят плоский и явный код.
- Игнорировать ошибки. Возврат `error` — основной механизм, и проверять его нужно явно.
- Запускать горутины без контроля завершения — это ведёт к утечкам. Используйте `context` и `sync.WaitGroup`.
- Делиться памятью без синхронизации. Запускайте тесты с флагом `-race`.

## FAQ

### Go быстрее Python?

Как правило, да: Go компилируется в машинный код и работает со статическими типами, поэтому в вычислениях и сетевых сервисах обычно заметно быстрее. Но для анализа данных Python часто выигрывает за счёт библиотек, написанных на C.

### Подходит ли Go для первого языка?

Да, благодаря простому синтаксису и строгим инструментам Go хорошо учит дисциплине. Однако по нему меньше учебных материалов для новичков, чем по Python или JavaScript.

### Есть ли в Go дженерики?

Да, обобщённые типы появились в языке начиная с версии 1.18. Они используются умеренно: в Go по-прежнему предпочитают простые и конкретные решения.
