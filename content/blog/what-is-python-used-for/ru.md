## Python в двух словах

**Python** — интерпретируемый язык общего назначения, созданный так, чтобы код было легко читать. Его главная идея: одна задача — один очевидный способ решения. Отступы вместо фигурных скобок, минимум служебных символов, понятные названия встроенных функций.

На практике это означает, что код на Python часто выглядит почти как псевдокод:

```python
prices = [120, 450, 80]
total = sum(prices)
print(f"Итого: {total}")
```

Python бесплатен, работает на Windows, macOS и Linux, а вокруг него огромная экосистема библиотек, которые ставятся одной командой через `pip`.

## Где Python применяют на практике

### Backend веб-сервисов

Фреймворки **Django**, **FastAPI** и **Flask** позволяют быстро собрать API, админ-панель или полноценный сайт. Django даёт «всё в коробке» (ORM, авторизация, админка), FastAPI — быстрые API с автодокументацией.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```

### Автоматизация рутины

Переименовать сотни файлов, выгрузить отчёт из Excel, проверить сайт по расписанию — типичные задачи на 20–50 строк кода.

```python
from pathlib import Path

for i, f in enumerate(sorted(Path("photos").glob("*.jpg")), 1):
    f.rename(f.with_name(f"photo_{i:03}.jpg"))
```

### Данные и аналитика

**pandas**, **NumPy** и **Jupyter** — стандарт для обработки таблиц, чистки данных и построения графиков. Аналитики используют Python там, где Excel уже не справляется.

### AI и машинное обучение

Основные ML-фреймворки (**PyTorch**, **scikit-learn**) и SDK крупных LLM-провайдеров в первую очередь ориентированы на Python. Поэтому RAG-системы, классификаторы и прототипы AI-агентов чаще всего пишут на нём.

### Боты

Библиотеки вроде **aiogram** и **python-telegram-bot** делают Python популярным выбором для Telegram-ботов: от простых уведомлений до ботов с оплатой и CRM-интеграцией.

## Слабые места Python

Честно о том, где Python — не лучший выбор:

- **Скорость.** Python медленнее C++, Go или Rust в задачах, где много вычислений в чистом коде. Тяжёлые операции обычно выносят в библиотеки, написанные на C (тот же NumPy).
- **Многопоточность.** Исторически GIL мешал выполнять Python-код параллельно в нескольких потоках одного процесса. Обходят это процессами, асинхронностью или нативными библиотеками.
- **Мобильная разработка.** Для iOS и Android Python практически не используют — там Swift, Kotlin, Flutter или React Native.
- **Frontend в браузере.** В браузере работает JavaScript, Python туда не попадает без экзотических решений.
- **Динамическая типизация.** Ошибки типов всплывают во время работы. Частично решается аннотациями типов и проверкой через **mypy**.

## Когда выбирать Python

| Задача | Python подходит? |
|---|---|
| API и backend | Да |
| Скрипты и автоматизация | Отлично |
| Анализ данных, ML, AI | Отлично |
| Telegram-боты | Да |
| Мобильное приложение | Нет |
| Высоконагруженный сервис с жёсткими задержками | Зависит от архитектуры |

Если проекту важны скорость разработки и готовые библиотеки — Python почти всегда хороший кандидат. Если критична производительность каждой миллисекунды или нужен мобильный клиент — смотрите на другие языки или комбинируйте.

## FAQ

### Python подходит для первого языка программирования?

Да. Читаемый синтаксис и быстрый результат делают его одним из самых удобных языков для старта. Главное — сразу практиковаться на реальных мини-задачах.

### Можно ли сделать на Python большой продакшн-проект?

Можно. Крупные сервисы используют Django и FastAPI в продакшене. Важно продумать архитектуру, тесты, типизацию и кеширование, а узкие места по скорости выносить в отдельные сервисы.

### Python 2 ещё актуален?

Нет. Python 2 больше не поддерживается, все новые проекты пишут на Python 3.
