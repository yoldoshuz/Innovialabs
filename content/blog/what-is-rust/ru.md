## Коротко: что такое Rust

**Rust** — компилируемый язык системного программирования, изначально развивавшийся в Mozilla, а теперь — независимым фондом Rust Foundation. Его главное обещание: **безопасная работа с памятью без сборщика мусора**. Ошибки, которые в C и C++ приводят к падениям и уязвимостям — обращение к освобождённой памяти, гонки данных, выход за границы, — в Rust в большинстве своём ловит компилятор.

При этом программы на Rust работают со скоростью, сопоставимой с C и C++, и не имеют пауз на сборку мусора.

## Как Rust добивается безопасности

В основе — **система владения (ownership)**:

- у каждого значения есть ровно один **владелец**;
- когда владелец выходит из области видимости, память освобождается автоматически;
- значение можно **заимствовать** (borrow): либо много раз только для чтения, либо один раз для изменения — но не одновременно.

Эти правила проверяет **borrow checker** во время компиляции.

```rust
fn main() {
    let s = String::from("привет");
    let len = length(&s);      // заимствуем, а не забираем
    println!("{s}: {len}");    // s всё ещё доступна
}

fn length(text: &String) -> usize {
    text.len()
}
```

Если попытаться изменить строку, пока на неё есть другая ссылка, код просто не скомпилируется. Цена — нужно научиться «договариваться» с компилятором.

## Почему разработчики любят Rust

- **Надёжность.** Если код скомпилировался, многие классы ошибок уже исключены.
- **Производительность.** Нет сборщика мусора, абстракции не добавляют накладных расходов во время работы.
- **Cargo.** Единый инструмент для сборки, зависимостей, тестов, документации и публикации пакетов. Новый проект создаётся одной командой `cargo new`.
- **Понятные ошибки компилятора.** Сообщения подробно объясняют проблему и часто предлагают исправление.
- **Современный язык.** Перечисления с данными, сопоставление с образцом, `Option` и `Result` вместо `null` и исключений.
- **Безопасная многопоточность.** Гонки данных отсекаются на этапе компиляции.

## Где Rust используют в продакшене

- **Системный софт**: компоненты операционных систем, драйверы — поддержка Rust добавлена, например, в ядро Linux.
- **Браузеры и движки**: части Firefox написаны на Rust.
- **Инфраструктура и облака**: прокси, хранилища, среды запуска изолированных функций.
- **Инструменты разработчика**: быстрые сборщики, линтеры и форматтеры для JavaScript и Python.
- **WebAssembly**: Rust — один из самых удобных языков для компиляции в Wasm.
- **Встраиваемые системы**, где важны предсказуемость и малый расход ресурсов.

## Насколько сложно учить Rust

Честно: **кривая обучения крутая**. Основные сложности:

| Что даётся трудно | Почему |
|---|---|
| Владение и заимствования | Непривычная модель, если вы пришли из языков со сборщиком мусора |
| Времена жизни (lifetimes) | Нужно явно описывать, сколько живут ссылки в сложных случаях |
| Асинхронный Rust | Много концепций и выбор рантайма |
| Скорость компиляции | Сборка крупных проектов заметно дольше, чем в Go |

Хорошая новость: после первых недель «борьбы» с компилятором большинство отмечает, что начинает писать более аккуратный код и на других языках. Начните с официальной книги «The Rust Programming Language» и небольших CLI-утилит.

## Когда Rust — не лучший выбор

- Нужно быстро собрать MVP или типовой веб-сайт — выигрыш в скорости не окупит время разработки.
- В команде нет времени на обучение, а сроки сжатые.
- Задача — анализ данных или ML-эксперименты, где экосистема Python богаче.

## FAQ

### Rust заменит C++?

Не полностью и не быстро: на C++ написано огромное количество работающего кода. Но в новых проектах, где критична безопасность памяти, Rust всё чаще выбирают вместо C++.

### Подходит ли Rust для веб-бэкенда?

Да, есть зрелые фреймворки, например Axum и Actix Web. Rust оправдан там, где важны производительность и надёжность; для типового CRUD-сервиса проще и быстрее взять Go, Node.js или PHP.

### Есть ли в Rust сборщик мусора?

Нет. Память освобождается автоматически, когда владелец значения выходит из области видимости, — это определяется на этапе компиляции, а не во время работы программы.
