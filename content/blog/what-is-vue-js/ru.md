## Vue.js в двух словах

**Vue.js** — это прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов. «Прогрессивный» значит, что его можно подключить к одной странице ради небольшого виджета, а можно построить на нём целое одностраничное приложение (SPA).

Две идеи, на которых всё держится:

- **Компоненты** — интерфейс собирается из независимых блоков: кнопка, карточка, форма.
- **Реактивность** — вы меняете данные, а Vue сам обновляет нужные места на странице.

Vue ценят за низкий порог входа, понятную документацию и то, что шаблоны похожи на обычный HTML.

## Однофайловые компоненты

Компонент во Vue обычно живёт в файле `.vue` (Single-File Component, SFC). В нём три части: логика, разметка и стили.

```vue
<script setup>
import { ref, computed } from "vue";

const count = ref(0);
const double = computed(() => count.value * 2);
</script>

<template>
  <button @click="count++">Нажато: {{ count }}</button>
  <p>Удвоенное значение: {{ double }}</p>
</template>

<style scoped>
button { padding: 8px 16px; }
</style>
```

Это рабочий пример счётчика. `scoped` означает, что стили действуют только внутри этого компонента.

## Как работает реактивность

- **`ref()`** создаёт реактивное значение. В скрипте к нему обращаются через `.value`, в шаблоне — напрямую.
- **`reactive()`** делает реактивным целый объект.
- **`computed()`** — вычисляемое значение, которое пересчитывается только при изменении зависимостей.
- **`watch()`** — запускает код, когда меняется конкретное значение, например чтобы отправить запрос.

Vue отслеживает, какие данные используются в шаблоне, и при изменении перерисовывает только то, что от них зависит.

## Composition API или Options API

| | Options API | Composition API |
|---|---|---|
| Как выглядит | Объект с разделами `data`, `methods`, `computed` | Функции `ref`, `computed` внутри `<script setup>` |
| Порог входа | Проще для самых первых шагов | Требует немного больше понимания |
| Большие компоненты | Логика одной задачи разбросана по разделам | Логику можно сгруппировать и вынести в composable |
| TypeScript | Поддерживается | Поддерживается заметно удобнее |

Оба API официально поддерживаются. Для новых проектов чаще выбирают **Composition API**: код легче переиспользовать через свои функции-composables, например `useCart()` или `useAuth()`.

## Pinia: общее состояние

Когда одни и те же данные нужны многим компонентам — пользователь, корзина, настройки, — их выносят в **хранилище**. Официальная библиотека для этого — **Pinia**.

```js
import { defineStore } from "pinia";

export const useCartStore = defineStore("cart", {
  state: () => ({ items: [] }),
  getters: {
    total: (state) => state.items.length,
  },
  actions: {
    add(item) {
      this.items.push(item);
    },
  },
});
```

В любом компоненте достаточно вызвать `useCartStore()`, и все подписанные компоненты обновятся при изменении корзины.

## Vue Router: страницы без перезагрузки

**Vue Router** — официальный роутер. Он связывает адреса с компонентами и переключает страницы без полной перезагрузки браузера.

```js
import { createRouter, createWebHistory } from "vue-router";
import Home from "./pages/Home.vue";
import Product from "./pages/Product.vue";

export const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: "/", component: Home },
    { path: "/product/:id", component: Product },
  ],
});
```

В шаблонах вместо `<a>` используют `<RouterLink to="/">`, а место для текущей страницы обозначают `<RouterView />`.

## С чего начать

1. Установите Node.js и создайте проект официальной командой `npm create vue@latest` — она предложит подключить Router, Pinia и TypeScript.
2. Разберите реактивность и компоненты на небольших примерах.
3. Добавьте маршруты и одно хранилище.
4. Если важны SEO и серверный рендеринг, посмотрите на **Nuxt** — фреймворк поверх Vue.

Официальная документация: [vuejs.org](https://vuejs.org/).

## Частые ошибки новичков

- Забывают `.value` при работе с `ref` в скрипте.
- Деструктурируют `reactive`-объект и теряют реактивность.
- Хранят в Pinia всё подряд, даже локальное состояние одной формы.
- Мутируют props внутри дочернего компонента вместо отправки события через `emit`.

## FAQ

### Vue или React — что выбрать?

Оба подходят для серьёзных проектов. Vue часто проще освоить благодаря HTML-подобным шаблонам и встроенным официальным решениям; у React больше сторонних библиотек и шире рынок специалистов. Выбирайте с учётом команды и задач.

### Нужен ли TypeScript для работы с Vue?

Не обязательно, Vue прекрасно работает на JavaScript. Но для средних и крупных проектов TypeScript помогает ловить ошибки раньше, а Composition API хорошо с ним сочетается.

### Подходит ли Vue для SEO-сайтов?

Обычное SPA на Vue рендерится в браузере, что хуже для поиска. Для сайтов, где важен SEO, используют Nuxt с серверным рендерингом или статической генерацией.
