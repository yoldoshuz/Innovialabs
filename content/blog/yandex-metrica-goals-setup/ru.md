## Короткий ответ

**Цель** в Яндекс Метрике — действие, ради которого существует сайт: отправка заявки, клик по телефону, переход в Telegram, оформление заказа. Без целей Метрика показывает только трафик, а с ними — какие источники приносят результат.

Настройка: **Метрика → ваш счётчик → Цели → Добавить цель**. Выберите тип, задайте условие, сохраните. Данные по цели начинают собираться с момента её создания — задним числом цели не считаются, поэтому настраивайте их до запуска рекламы.

## Типы целей и когда какой выбирать

| Тип цели | Что считает | Когда использовать |
|---|---|---|
| **Посещение страниц** | Заход на URL по условию | Страница «Спасибо», корзина, оформление заказа |
| **JavaScript-событие** | Вызов `reachGoal` из кода сайта | AJAX-формы, калькуляторы, любые действия без смены URL |
| **Отправка формы** | Событие submit у формы на странице | Простые HTML-формы |
| **Клик по номеру телефона** | Нажатие на ссылку `tel:` | Мобильный трафик, бизнес с продажами по телефону |
| **Переход в мессенджер** | Клик по ссылке на Telegram, WhatsApp и т.п. | Когда заявки приходят в чаты |
| **Клик по email, скачивание файла** | Соответствующие ссылки | Прайс-листы, презентации, контакты |
| **Составная цель** | Последовательность шагов | Воронка: каталог → карточка → корзина → заказ |

Часть целей Метрика может создать автоматически (**автоцели**) — например, клики по телефону и мессенджерам. Это удобно для старта, но названия и логику таких целей стоит проверить вручную.

## Как настроить основные цели

**Посещение страницы.** Укажите условие: «URL совпадает», «URL содержит», «URL начинается с» или регулярное выражение. Для страницы благодарности подойдёт «URL содержит» `/thank-you`. Проверьте, что на эту страницу нельзя попасть иначе, чем после заявки, — иначе цель будет завышена.

**JavaScript-событие.** Самый надёжный вариант для современных сайтов. В Метрике задайте **идентификатор цели**, например `lead_form`, а разработчик добавляет вызов в момент успешной отправки (после ответа сервера, а не по клику на кнопку):

```js
ym(XXXXXXXX, 'reachGoal', 'lead_form');
```

Вместо `XXXXXXXX` — номер вашего счётчика. Идентификатор чувствителен к написанию: `lead_form` и `Lead_Form` — разные цели.

**Отправка формы.** Метрика покажет найденные на странице формы. Работает, если форма отправляется стандартно. Если форма уходит через JavaScript без события submit, цель может не срабатывать — тогда используйте JavaScript-событие.

**Клик по телефону и мессенджеру.** Номер должен быть ссылкой вида `tel:+998...`, а мессенджер — обычной ссылкой. Номер, нарисованный картинкой или текстом без ссылки, Метрика не отследит.

**Составная цель.** Задайте до нескольких шагов, каждый — со своим условием. В отчётах видно, на каком шаге люди отваливаются. Полезно для интернет-магазинов и многошаговых форм.

## Как проверить, что цель работает

1. Откройте сайт с параметром `?_ym_debug=1` в адресе, например `site.uz/?_ym_debug=1`.
2. Откройте консоль браузера (F12 → Console).
3. Выполните целевое действие. В консоли должно появиться сообщение о достижении цели с её идентификатором.
4. Через некоторое время проверьте **Отчёты → Конверсии**: цель должна появиться с ненулевым значением.

Проверяйте и на десктопе, и на телефоне, и с выключенными блокировщиками рекламы — часть посетителей их использует, поэтому небольшое расхождение с CRM нормально.

## Как использовать цели в Яндекс Директе

- **Привяжите счётчик** к рекламной кампании в её настройках.
- Отметьте **ключевые цели** — те, по которым Директ будет оптимизировать показы. Для автостратегий с оптимизацией конверсий нужна цель, по которой уже накапливаются достижения.
- Можно указать **ценность конверсии**, если заявки разной важности.
- Цели доступны для **ретаргетинга**: показывать рекламу тем, кто дошёл до корзины, но не оформил заказ.

## Частые ошибки

- Цель на клик по кнопке «Отправить» вместо успешной отправки — считаются и пустые формы, и ошибки валидации.
- Одна общая цель на все формы — непонятно, какая форма работает.
- Страница «Спасибо» открывается при обновлении или из закладок — конверсии дублируются.
- Счётчик установлен не на всех страницах или дважды.
- В Директ передаются «мягкие» цели вроде просмотра двух страниц — алгоритм учится приводить нецелевой трафик.

## FAQ

### Сколько целей стоит создавать?

Столько, сколько у вас реальных точек контакта: каждая форма, телефон, каждый мессенджер. Плюс одна-две составные цели для воронки. Десятки целей «на всякий случай» только мешают читать отчёты.

### Почему число целей в Метрике не совпадает с заявками в CRM?

Причины обычно в блокировщиках, отклонённых cookie, повторных отправках и спаме. Сравнивайте тренды, а для точного учёта связывайте Метрику с CRM через сквозную аналитику.

### Можно ли передать в Метрику офлайн-продажи?

Да, Метрика поддерживает загрузку офлайн-конверсий, привязанных к посетителю по идентификатору. Это позволяет видеть, какая реклама привела не только к заявке, но и к оплате.
